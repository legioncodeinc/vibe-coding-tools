## Captured facts

Saving a page does not necessarily publish it. For stale live content, confirm the saved and published versions and test in a private browser. For a pending domain or SSL warning, verify record type, host, value, conflicts, propagation, and proxy mode. For a 404, check domain assignment, the intended published page, default page, and URL path.

## Safety caveat

Preserve the current live version and content before editing. Do not delete pages, domains, redirects, or DNS records to troubleshoot a publication delay without first identifying the exact mismatch.
