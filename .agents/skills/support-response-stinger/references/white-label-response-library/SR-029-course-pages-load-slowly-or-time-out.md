# SR-029: Course pages load slowly or time out

## Use when

Use when an enrolled learner cannot load a course page reliably.

## Required evidence

- Workspace, course, offer, learner, page address, timestamp and timezone, publication and enrollment state, and comparison with another appropriate learner or network.

## Customer-facing email

**Subject:** {ticket_id}: Checking the slow course page

Hi {customer_first_name},

I understand that a course page is loading slowly or timing out for the learner. We need to compare publication, offer, enrollment, and access state without changing the learner's entitlement.

Please send the workspace, course and offer names, affected learner, page address, and the latest time with timezone. Include the current publication and enrollment states and tell me whether the same page loads for another appropriate learner or on another network.

Please do not republish the course, recreate the offer, or re-enroll the learner. I will compare the same page across the authorized contexts and inspect the existing access state. If it still times out, I will send the evidence to our technical team without changing billing or enrollment history.

{agent_name}
{agency} Support

## Agent notes

Evidence class `F1`. Remediation class `R1`. Apply `HR-11`. Separate page performance from publication, offer, enrollment, and entitlement. No republish, purchase recreation, or re-enrollment before history is checked.
