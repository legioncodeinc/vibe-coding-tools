The article states that V1 APIs reached end of support on 2025-12-31. Existing V1 connections may continue to function but no longer receive support or updates. Current implementation should use V2 and private integrations where applicable.

## Safety caveat

Do not request or reproduce API keys, bearer tokens, OAuth client secrets, authorization headers, or webhook signatures in email. A migration response must identify the endpoint, version, authentication method, and redacted error before recommending changes.
