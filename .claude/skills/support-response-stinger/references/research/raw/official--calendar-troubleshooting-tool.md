## Captured facts

The calendar diagnostic view can identify missing user availability, third-party conflicts, existing bookings, manual blocks, minimum-notice rules, booking-window limits, day limits, slot limits, and buffers. It can also surface connection and permission problems.

The response component can ask a customer to report the reason code shown for one affected slot. That is safer and faster than asking them to change every calendar setting.
