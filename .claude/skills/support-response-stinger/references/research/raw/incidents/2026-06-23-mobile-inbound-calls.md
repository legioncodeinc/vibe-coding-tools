# Issues Receiving Calls on Mobile App

- URL: https://status.gohighlevel.com/incident/932427
- Fetched: 2026-09-04
- Source type: official-status-incident
- Incident observed: 2026-06-23
- Trend window: 2026-06-04 through 2026-09-04 inclusive
- Window role: direct recent incident evidence

## Captured facts

For some customers using the mobile app as the calling channel, the calling preference switched to the web app and prevented mobile receipt of calls. The provider implemented a fix and reported restored service.

## Safety caveat

After recovery, verify the intended calling channel, user assignment, app notification and microphone permissions, and one controlled inbound call. Do not change organization-wide routing to fix one affected user without checking the routing impact.
