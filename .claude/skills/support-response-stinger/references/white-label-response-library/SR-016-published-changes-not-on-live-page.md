# SR-016: Published changes do not appear on the live page

## Use when

Use when saved and published changes are not visible on the customer-facing page.

## Required evidence

- Workspace, asset and live page address, saved version, published version, publication time and timezone, private-browser result, and recent changes.

## Customer-facing email

**Subject:** {ticket_id}: Comparing your published and live page

Hi {customer_first_name},

I understand that changes marked as published are not appearing on the live page. We need to compare the saved, published, and public versions before publishing again.

Please send the workspace, asset name, live page address, publication time with timezone, and a brief description of the expected change. Confirm what the saved version and published version show, then open the live page once in a private browser and tell me what appears there. Include any recent edits or assignment changes.

Please do not repeatedly publish, delete, or recreate the page. I will compare the three versions and current internal service state. If the verified published version remains absent from the live page, I will send the preserved evidence to our technical team.

{agent_name}
{agency} Support

## Agent notes

Evidence class `F1`. Remediation class `R1`. Apply `HR-13`. A private-browser comparison is safe; deletion, recreation, and repeated publishing are not. Escalate only after confirming the saved and published versions.
