# HeyGen API reference

| Concern | Required decision |
|---|---|
| Creation | Which documented endpoint and response represents the job |
| Completion | Polling, a documented webhook, or both |
| Delivery | Who can retrieve the resulting asset and for how long |
| Retry | Local idempotency key and duplicate-event policy |
| Human likeness | Consent, authorization, and permitted avatar or voice material |
