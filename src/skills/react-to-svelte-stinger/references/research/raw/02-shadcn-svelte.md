## What it is

"An unofficial, community-led Svelte port of shadcn/ui" - "not affiliated with shadcn" (blessed by him). "This is not a component library. It is how you build your component library." Ported to Svelte by Huntabyte & CokaKoala.

## Copy-in model

The Open Code principle: "hands you the actual component code" - you own and edit it directly. Distribution via a Schema ("flat-file structure that defines the components, their dependencies, and properties") and a CLI ("command-line tool to distribute and install components across projects with cross-framework support").

## Primitives

Components are "built with Bits UI and Tailwind CSS." (Melt UI is not named on this page; Bits UI is the named primitive layer.)

## Component catalog (selected)

Accordion, Alert Dialog, Avatar, Badge, Breadcrumb, Button, Calendar, Card, Carousel, Chart, Checkbox, Combobox, Command, Context Menu, Data Table, Date Picker, Dialog, Drawer, Dropdown Menu, Input, Popover, Select, Sheet, Sidebar, Slider, Switch, Table, Tabs, Toast (Sonner), Toggle, Tooltip - about 60 total.

Theming and Dark Mode are separate docs pages (theming via CSS variables per the docs navigation).
