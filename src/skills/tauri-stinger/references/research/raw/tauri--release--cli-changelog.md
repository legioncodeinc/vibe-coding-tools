## Archived evidence

The release line inside the cutoff ran from Rust `tauri-cli` 2.10.1 on 2026-03-04 through 2.11.4 on 2026-06-28.

Version 2.10.1 fixed keys created by `tauri signer generate` with an empty password. The changelog explicitly says keys generated by CLI 2.9.3 through 2.10.0 were broken and must be regenerated.

Version 2.11.0 added Android and iOS file associations, NSIS uninstaller art, `--no-sign` and `--archive-only` for iOS builds, and the Windows `minimumWebview2Version` setting. Version 2.11.3 fixed invalid aliased imports produced by `tauri migrate`, honored `NDK_HOME`, and skipped bundle generation for `tauri android run`. Version 2.11.4 fixed absolute symlinks in AppImage metadata.

## Archive interpretation

Updating the CLI does not repair an already generated broken signing key. Migration output from an older CLI must be rechecked rather than trusted.
