- Component type: Stinger, paired with `tauri-worker-bee`
- Domain: Tauri 2 desktop and mobile application engineering
- Trigger boundary: Use for Tauri-specific configuration, upgrades, migration, IPC, runtime authority, plugins, sidecars, mobile bridges, updater integration, bundling, signing, and native verification
- Exclusions: General Rust language design, frontend-framework internals, formal security audit, and CI platform architecture remain with their specialist Bees and Stingers
- Harness targets: Claude Code, Cursor, ChatGPT Codex, and Claude Cowork
- Focus: Development-focused, so the exact Queen Bee Critical Directive and Ship Gate are required
- Research window: 2026-03-03 through 2026-09-03, with source retrieval completed at the cutoff
- Source policy: Official Tauri documentation, official Tauri repositories, immutable release tags, and upstream primary sources only
- AI policy: Tauri facts must remain distinct from derived AI application designs. No first-party AI reference application was found during the sweep, so every AI-specific topology and example must be labeled as derived.
- Currency policy: Version numbers are dated observations, never timeless defaults. Runtime code must inspect the target project and refresh current releases before changing dependencies.

## Outcomes

The Stinger must equip its paired Bee to:

1. Inspect an existing or greenfield Tauri project without changing it.
2. Align Rust, JavaScript, CLI, and plugin dependency families deliberately.
3. Migrate Tauri 1 applications to Tauri 2 without treating CLI automation as complete proof.
4. Implement typed commands, events, Channels, and managed state with explicit trust boundaries.
5. Design least-privilege capabilities, permissions, scopes, sidecar argument rules, and secret handling.
6. Choose and implement hosted-provider, local-sidecar, or native-plugin AI topologies.
7. Persist preferences, durable application data, and secrets through different storage classes.
8. Test renderer behavior, Rust logic, IPC contracts, packaged binaries, and real target behavior at proportionate depth.
9. Build, sign, update, and distribute desktop and mobile applications with evidence from final artifacts.
10. Refresh the dated release snapshot from primary sources before making currency claims.
