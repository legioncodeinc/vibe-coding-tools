| Field | Type | Required | Description (verbatim) |
|---|---|---|---|
| `prompt` | string | yes | "A text description of the image you want to generate" |

| `aspect_ratio` | string | no | "Aspect ratio of the generated image" — values seen: `1:1`, `4:3`, `3:4`, `16:9`, `9:16` (docs elsewhere list 11 options incl. a "match input image" option) |

## Notes captured from the Replicate README
- "Create images with accurate, legible text" across multiple languages.
- "Combine up to 14 images while maintaining consistency and resemblance of up to 5 people."
- Advanced editing: camera angles, lighting, color grading, depth of field, specific image regions.
- "images in various aspect ratios and at resolutions up to 4K."
- Google Search access for real-time information.
- "All images generated by Nano Banana Pro include SynthID watermarks, Google's imperceptible digital watermarking technology for identifying AI-generated content."

## Documented limitations (verbatim from Replicate README)
- "sometimes produce inaccurate or unexpected results"
- Text: "occasional issues with grammar, spelling, or cultural nuances" (varies by language)
- "Advanced features like masked editing and lighting changes may create visual artifacts or unnatural results"
- "Character consistency is generally reliable but not perfect every time"
- The model "may at times be at capacity" (hence `allow_fallback_model`)

## Appendix — Replicate's own prompting guidance
Source: https://replicate.com/blog/how-to-prompt-nano-banana-pro (vendor-blog, fetched 2026-08-17)

- Reasoning: the model has "intermediary prompting layers that help the model make logical
  conclusions" — you can give it tasks like "write the answers to the questions in pencil. show
  your work" and it reasons before drawing.
- Text/design: maintains "pixel-perfect text accuracy while fully embracing your stylistic input";
  handles non-English text; tolerates long, detailed prompts with precise adherence.
- Character consistency: process "up to 14 reference images simultaneously"; maintains character
  appearance across scenes. Editing idiom shown: "Make him [insert scenario here]. Keep his
  whiteboard style, but make the surroundings realistic."
- World knowledge: can deduce landmarks from GPS coordinates; needs Search tools for real-time data.
- Stated limitation: cannot access real-time weather/current info without tools; "structured tool
  calling coming soon."
- Only parameters referenced in the post: `prompt` and `aspect_ratio` (e.g. `"1:1"`).
