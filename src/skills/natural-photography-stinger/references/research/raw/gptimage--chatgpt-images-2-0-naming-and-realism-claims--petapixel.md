## Product naming — resolves part of the user's terminology

PetaPixel uses **"ChatGPT Images 2.0"** throughout, matching OpenAI's
ChatGPT-surface branding. The article does not use the API identifier
`gpt-image-2`.

So there are three names for the same April 2026 release:
- **ChatGPT Images 2.0** — consumer / ChatGPT surface name
- **gpt-image-2** — API model identifier
- **chatgpt-image-latest** — API alias pointing at the ChatGPT-served model

The user's "ChatGPT Image 2" is a near-correct rendering of the consumer name.
(It is *not* paired with any "Sol 5.6 ULTRA" tier — see the Sol disambiguation
file.)

## What was announced

- Reasoning capabilities integrated into image generation "for the first time"
- Up to **eight coherent outputs in a single request** with character continuity
- Availability across ChatGPT, Codex, and the API

## Photorealism claims — the key quote

> the model is "better able to capture the defining characteristics of
> photos—including the tiny flaws that add realism"

and shows "greater consistency in texture, lighting, composition, and fine
detail" across styles.

"**The tiny flaws that add realism**" is OpenAI's own framing of the
photorealism problem, and it validates the prompting tactic of explicitly
requesting imperfection rather than perfection.

## Resolution and aspect ratio

- up to **2K resolution** via the API
- aspect ratios from **3:1 (wide) to 1:3 (tall)**

## Acknowledged limitations

OpenAI acknowledges continued limitations with **"precise physical reasoning or
highly detailed structural accuracy."**

Read against photorealism: this is the residue that produces impossible optics
(bokeh that doesn't match the stated aperture, reflections that don't
reciprocate, shadow directions that disagree between subject and background),
plus the classic structural failures — hands, teeth, jewellery clasps,
eyeglass hinges, and background text.
