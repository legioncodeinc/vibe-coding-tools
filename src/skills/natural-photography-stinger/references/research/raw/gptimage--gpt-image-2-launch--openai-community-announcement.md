# Introducing gpt-image-2 — available today in the API and Codex
- URL: https://community.openai.com/t/introducing-gpt-image-2-available-today-in-the-api-and-codex/1379479
- Fetched: 2026-08-17
- Source type: official-docs (OpenAI staff announcement on OpenAI Developer Community)

## Model + date

**`gpt-image-2`**, launched **April 21, 2026**, available immediately in the API
and in Codex.

This is the official identifier. The product is *not* named "ChatGPT Image 2" in
any OpenAI channel; the ChatGPT-surface alias in the API is
`chatgpt-image-latest`.

## Capabilities claimed

> "stronger editing, better layouts, improved text rendering, and more reliable
> instruction-following"

Also cited:
- support for "more aspect ratios and resolutions up to 2K"
- "stronger structured generation (diagrams, infographics, charts, posters, comics)"
- "Thinking mode for richer workflows" — integration with reasoning models so
  image generation can be planned in context before rendering.

## Pricing (per 1M tokens)

- Input: **$8.00**
- Cached input: **$2.00**
- Output: **$30.00**

## Third-party benchmark claims quoted in the announcement

- "#1 spot across all Image Arena leaderboards"
- "an unprecedented +242 point lead in Text-to-Image"
- score of **1,512** on the Text-to-Image Arena benchmark

## Positioning

> designed for "production workflows, where images need to be accurate,
> readable, on-brand, localized, formatted for the destination surface, and
> usable without heavy cleanup."

## Notable absence

The announcement contains **no explicit photorealism claim**, no quality-tier
table, and no input-fidelity guidance. The marketing emphasis is on text
rendering, layout and instruction following — i.e. the *graphic design* axis,
not the *photographic* axis. This is a signal that photorealism still has to be
driven entirely by prompt craft rather than by a model-level mode or preset.
