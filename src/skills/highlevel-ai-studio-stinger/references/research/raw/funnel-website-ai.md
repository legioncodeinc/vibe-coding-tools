## **What is Funnel & Website AI?**

Funnel & Website AI is HighLevel’s AI-powered page creation experience for building funnel and website pages from prompts, guided inputs, URLs, and images. It helps users generate layouts, copy, visuals, and page structure more quickly while still keeping builder controls available for manual refinement. This matters because it gives both beginners and experienced builders a faster way to launch polished pages without starting from scratch.

Funnel & Website AI includes multiple creation paths and editing tools so users can choose the workflow that fits their needs:

| Path/Feature | Description |
| --- | --- |
| Assist | Helps users generate pages with guided presets and structured inputs such as business niche, goal, audience, tone, and layout preferences. |
| Build | Gives users more creative freedom by letting them describe exactly what they want the AI to create. |
| Chat-based editing | Makes it easier to update copy, sections, layout ideas, and design direction in real time while working inside the page builder. |
| Ask AI + Settings Side-by-Side | Keeps AI assistance and builder controls close together so users can refine content and styling without constantly switching views. |
| Import from a Link or Image | Helps users create pages inspired by a public URL or image reference. |
| SEO Support | Helps generate page titles, descriptions, and content suggestions that support stronger page optimization. |

## **Key Benefits of Funnel & Website AI**

Funnel & Website AI is designed to help users create better pages in less time, with fewer revisions and less design guesswork. These benefits are especially useful for agencies, marketers, and business owners who want a faster path from idea to launch.

- **Faster page creation**: Generate page structure, copy, visuals, and layout direction in minutes instead of building everything manually.

- **Guided or flexible workflows**: Start with structured inputs in Assist or use Build when you already know exactly what you want.

- **Easier real-time editing**: Make changes through AI chat while still having traditional builder settings available nearby.

- **More polished results**: The updated experience is intended to improve design quality, spacing, structure, and overall visual consistency.

- **Less manual cleanup**: Stronger layout rules and more consistent styling help reduce broken sections and unexpected formatting issues.

- **Better publishing readiness**: AI-assisted SEO suggestions and cleaner page generation can help users prepare pages faster before launch.

## **Choose Your AI Creation Path: Assist or Build**

Funnel & Website AI gives users two primary ways to create a funnel page, depending on how much guidance or control they want. Choosing the right path at the start helps generate more relevant results and makes the building process smoother from the beginning. The current HighLevel experience presents these two paths directly inside the Ask AI panel.

### **1\. Assist**

Assist is the guided path for users who want HighLevel to help shape the page before generation. It uses structured inputs like the funnel page name, business niche, page goal, target audience, and offer details to create a more tailored starting point. This option is especially helpful when you want direction, want to move quickly, or are not sure how to phrase a detailed prompt yourself.

Users can fill in fields such as:

- Name of the funnel page

- Business niche

- Goal of the funnel page

- Target audience

- What is being offered


Once those details are entered, users can generate the page directly or continue customizing before generation.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068214474/original/H2zQrvTrNAOPKiZBSWSvYiyHCbuh51Arbw.png?1775029087)

### **2\. Build**

Build is the flexible path for users who already have a clear vision for the funnel. Instead of following guided fields, users can type a direct request and ask the AI to plan, build, or modify the page based on their instructions. This is ideal for users who want more creative freedom, have a specific campaign structure in mind, or want to describe copy and design direction in their own words.

Build also includes suggested prompt starters to help users move faster, such as creating a high-converting funnel or improving copy for impact.

![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068214751/original/jl4JD-3FexCFb8BEUXvgZhLzO2XYSRZ37g.png?1775029135)

## **Chat Mode and Side-by-Side Editing**

Chat-based editing makes ongoing changes more conversational and efficient. Instead of manually digging through settings for every update, users can ask the AI to rewrite text, adjust sections, suggest design improvements, or refine messaging directly inside the builder.

The side-by-side experience matters because it combines AI assistance with traditional editing controls. That means users can:

- Ask AI to improve copy

- Refine layout direction

- Adjust content section by section

- Review and tweak styling through builder settings

- Make faster decisions without interrupting their workflow


This workflow is especially useful after the first generation, when the page already exists and needs refinement rather than full recreation.

## **AI-Powered SEO Suggestions**

Funnel & Website AI can help users move faster on SEO by generating suggested titles, descriptions, and content direction during page creation. That gives users a stronger starting point when preparing a page for search visibility.

AI-generated SEO suggestions should still be reviewed before publishing. This matters because page goals, brand language, and search intent may require manual refinement.

Helpful follow-up tasks after AI generation:

- Review the page title for clarity and relevance

- Refine the meta description for search intent

- Confirm headings match the page purpose

- Update page copy to reflect your brand voice

- Add any custom metadata needed before publishing

A strong setup process helps users get better first-generation results and reduces the need for excessive edits later. Starting with the right mode, inputs, and expectations makes the AI output more relevant and easier to refine.

1. Navigate to **Sites** → **Funnels** or **Websites** in your HighLevel sub-account. Click **Build with AI** to create a new funnel or website asset OR Open an existing Website or Funnel.



![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/155068222784/original/Ghr7x1RQlfjTMyo0XjXQlLH38rZirK3d_g.png?1775032966)

**Assist** for a guided setup experience

**Build** for direct prompt-based creation

## **Frequently Asked Questions**

**Q: When should I use Assist instead of Build?**

Use Assist when you want a guided starting point and would benefit from presets or structured inputs. Use Build when you already have a clear page concept and want to describe it directly.

**Q: Does importing from a link or image work the same way as cloning a funnel or website?**

No. AI reference-based creation is best treated as inspiration-driven generation.

**Q: Can I still manually edit the page after AI generates it?**

Yes. The AI experience is meant to speed up creation, but users can continue refining the page using chat-based edits and standard builder settings.

**Q: Will the AI-generated SEO content be enough on its own?**

It is a strong starting point, but it should still be reviewed for accuracy, search intent, and brand voice before publishing. HighLevel also supports manual metadata updates.

**Q: Do I need design experience to use Funnel & Website AI?**

No. One of the main benefits of the tool is that it reduces design complexity by generating layouts, copy, and page structure for you.
