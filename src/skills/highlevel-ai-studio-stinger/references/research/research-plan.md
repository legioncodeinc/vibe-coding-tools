# Research plan: HighLevel AI Studio

## Question set

1. What does HighLevel officially call AI Studio, Vibe, vibe coding, Content AI, and its other AI builders?
2. Which product should handle each requested output: code-backed site or app, standard funnel or website, WordPress page, marketing copy, blog, email, or automated agent?
3. How are AI Studio projects created, edited, tested, connected, published, reused, and governed?
4. What are the current prerequisites, plan limits, pricing rules, and access controls?
5. Which behaviors are documented limitations, and which capabilities remain undocumented?
6. Where do official sources conflict or supersede earlier guidance?

## Search and selection rules

- Search the official HighLevel Support Portal and official HighLevel product blog.
- Accept sources published or visibly modified from 2026-03-03 through 2026-09-03.
- Prefer the newest product-specific support article when an older overview conflicts with it.
- Keep launch posts as historical evidence only when a newer support article changes the operational rule.
- Do not import detailed UI steps from sources outside the window.
- Record exact URLs, visible source dates, fetch date, source type, and archival method.
- Preserve raw source prose even when it contains typography prohibited for newly authored repository prose.

## Search themes

- `AI Studio`, `AI Studio (Vibe)`, `vibe coding`, `vibe code`
- `AI Content Studio`, `Content AI`, `Ask AI`, `Blog Post AI`, `Email AI`
- `AI website builder`, `Funnel & Website AI`, `WordPress AI-Powered Page Builder`
- `Visual Edits`, `Code Editor`, `forms`, `calendars`, `workflow trigger`
- `publish`, `custom domain`, `Advanced SEO`, `clone`, `Snapshot`
- `pricing`, `usage limits`, `AI Employee`, `Labs`, `permissions`

## Archive method

Pages are scraped as clean Markdown with Firecrawl on 2026-09-03. Each raw file receives a provenance header. The distillation cites the local raw filename for every factual row or paragraph. Search-result snippets are discovery aids only and are not used as evidence when a full official page is available.
