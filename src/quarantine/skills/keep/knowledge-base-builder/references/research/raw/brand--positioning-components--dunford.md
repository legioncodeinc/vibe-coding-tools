# Positioning components (April Dunford)

- **Title:** A Quickstart Guide to Positioning
- **URL:** https://www.aprildunford.com/post/a-quickstart-guide-to-positioning
- **Fetched:** 2026-08-17
- **Source type:** primary practitioner source (the author of Obviously Awesome, on her own
  site)

## The five components

| Component | Definition |
|---|---|
| Competitive alternatives | What customers would do if the product did not exist |
| Key unique attributes | Capabilities the product has that the alternatives lack |
| Value | The benefit those capabilities enable for the buyer |
| Target customer characteristics | Who cares most about that differentiated value |
| Market category | The context that makes the value obvious |

## Order of work

Start with competitive alternatives and work forward: alternatives, then unique attributes,
then value, then customer characteristics, then market category. The order matters because
each element is derived from the one before it, so a category chosen first will not survive
contact with the alternatives.

## Key definitions, quoted

"Positioning defines how your product is a leader at delivering something that a well-defined
set of customers cares a lot about."

"Good positioning sets off a set of assumptions about my product that are true. Bad
positioning sets off a set of assumptions about my product that aren't true."

## Pitfalls named

- Defining competitive alternatives too broadly, including phantom competitors that
  customers never actually consider.
- Assuming a new market category has to be created. The source states that 90 percent of
  recent public technology companies positioned into existing markets. No citation is given
  for that figure, so treat it as the author's assertion.

## Why this is the right skeleton for a capture-sourced brand brief

Every one of the five components is a thing a founder says out loud, repeatedly, on sales
calls and in pitches. Competitive alternatives in particular surface as offhand remarks
about who the prospect is comparing against. This makes the framework unusually well matched
to material reconstructed from meetings, and it makes the gaps visible: a project that has
never articulated its target customer characteristics will produce an empty cell rather than
a vague paragraph.
