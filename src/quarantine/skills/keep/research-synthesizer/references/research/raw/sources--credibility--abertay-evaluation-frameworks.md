## The frameworks named, and what each is said to be for

| Framework | Stated best use |
|---|---|
| CRAAP test | Academic sources. "quick, easy to remember, and works well for most general academic sources" |
| 5 Ws | "news, websites, or AI-generated content". Purpose: "explore authorship and purpose" |
| Lateral reading | Checking credibility online |
| SIFT | "digital content" |
| PROMPT | "evaluate academic and grey literature" |
| RAVEN | Analysing arguments |

## The claim this source actually supports

That there is **no single source-evaluation framework**, that the frameworks are matched to
source type, and that a guide from a university library treats picking the right one as the
first decision. It explicitly separates the framework for academic sources from the
framework for news and AI-generated content, and separates both from the framework for
grey literature.

## What this source does NOT provide

- The expansion of the CRAAP, PROMPT, RAVEN, SIFT, or 5 Ws acronyms.
- Any discussion of bias, purpose, commercial interest, or funding.
- Any guidance on grading a source beyond naming which framework applies.

This is a thin source. It is retained only for the framework-selection point above. No
claim about how any individual framework works is drawn from it.
