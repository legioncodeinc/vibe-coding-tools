## Extracted content

### Technical specifications

| Spec | Stated requirement |
|---|---|
| File formats | PDF, PPTX, DOC and DOCX. PDF recommended for consistent rendering |
| Maximum file size | 100 MB |
| Maximum pages | 300 |
| Recommended slide count | 5 to 15 |
| Portrait dimensions | 1080 x 1350 px, 4:5 |
| Square dimensions | 1080 x 1080 px, 1:1 |
| Landscape dimensions | 1920 x 1080 px, 16:9 |
| Minimum resolution | 300 DPI for text clarity |
| Safe margin | 50 px from all edges |

Note the gap between the 300-page ceiling and the 5 to 15 recommendation. This is the same
ceiling-versus-effective-limit pattern seen on every surface in this archive.

### Per-slide copy guidance

- Maximum 60 words per slide.
- Minimum body font size 24 pt.
- No more than 6 to 8 lines of text per slide.
- **Cover slide:** a bold claim or a data point, minimal visual clutter, a swipe indicator.
- **Body slides:** one key point per slide, alternating text-heavy and visual slides.
- **CTA slide:** restate the key takeaway, one call to action, branding.

## Claims this source supports

1. A carousel outline is a **word-budgeted** artifact. At 60 words per slide across 5 to 15
   slides, the whole piece is 300 to 900 words. That is a hard planning constraint, and it
   is why the skill produces per-slide copy rather than a topic list.
2. The one-point-per-slide rule means a carousel is structurally a sequence of distinct
   claims, which makes it the natural home for the multi-angle expansion of a source rather
   than a restatement of one angle.
3. The cover slide carries the same job as a post's first line: it is the fold. A carousel
   whose cover slide is a title rather than a claim has spent its only visible surface on
   nothing.

## Caveat

Specifications on this page are not sourced to LinkedIn documentation. Dimensions and
limits are the class of fact that changes. Verify before a user builds against them.
