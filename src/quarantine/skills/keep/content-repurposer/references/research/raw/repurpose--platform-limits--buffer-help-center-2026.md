# Character limits for each social network (Buffer Help Center)

- **Title:** Character limits for each social network
- **URL:** https://support.buffer.com/article/588-character-limits-for-each-social-network
- **Published:** no date shown on page
- **Fetched:** 2026-08-17
- **Source type:** vendor-official (the publishing tool's own enforced limits, not a blog)

## Why this source ranks above the character-limit blog farm

A search for platform character limits returns dozens of near-identical SEO pages from
counter tools, none of which state a method. This page is different in kind: Buffer is a
scheduling product that has to reject an over-length post at the API boundary, so these
numbers are what its integrations actually enforce. It is still second-hand relative to the
platforms themselves, and it carries no date, which is a real weakness for a fast-moving
fact. Treat it as the best available cross-platform reference and re-verify anything that a
draft is about to be sized against.

## Extracted content, verbatim where quoted

| Network | Limit as stated |
|---|---|
| X free | "X Free users: 280 characters" |
| X paid | "X Basic, Premium and Premium + users: 25,000 characters" |
| LinkedIn | "3,000 for posts and 1,250 for first comments" |
| Facebook | "5,000 for post/reel captions and 5,000 for first comments" |
| Instagram | "2,200 for post/reel captions, 2,200 for first comments, and 120 for story captions" |
| Threads | "500 for posts and 50 for topics" |
| Mastodon | "Varies by server (default 500)", read from the connected server |
| Pinterest | 500 |
| TikTok | 2,200 |
| YouTube Shorts | 5,000 |
| Bluesky | 300 |
| Google Business Profile | 1,500 |

Additional note stated on the page: "Images can also take up character space in your post"
on certain platforms including X and LinkedIn, where images consume part of the character
allowance.

## Claims this source supports

1. The hard ceilings a repurposed pack must respect on X, LinkedIn, Facebook, Instagram,
   and Threads.
2. Facebook's 5,000-character ceiling is more than 60% larger than Instagram's 2,200, which
   is why a Facebook source post frequently cannot survive a straight paste to Instagram.
3. Attached media can consume character budget on X and LinkedIn, so a limit computed
   against text alone can still fail at post time.

## Conflicts with other sources in this archive

## Gap
