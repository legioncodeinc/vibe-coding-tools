# Instagram Carousels Now Support 20 Slides and Individual Captions

- **Title:** Instagram Carousels Now Support 20 Slides and Captions
- **URL:** https://carouselpost.io/digest/instagram-carousels-20-slides-individual-captions-2026
- **Published:** 2026-06-19
- **Fetched:** 2026-08-17
- **Source type:** community / secondary reporting (aggregator citing tech press)

## Evidence quality, stated plainly

This is a third-hand report. The publisher cites Engadget and a Pop Base post on X. It does
NOT cite a Meta announcement, an Adam Mosseri statement, or any Instagram documentation.
The official Instagram help page for carousel posts was attempted directly at
https://help.instagram.com/1638251932708206 and returned only page metadata with no body
content, so no first-party confirmation was obtained in this sweep. **Named gap: this
archive has no first-party Meta source for any Instagram behavior.**

## Extracted content

- Maximum slides per carousel expanded from 10 to 20.
- Each slide now supports its own individual caption, where previously one caption covered
  the whole post.
- Rollout reported as 2026-06-19.
- Quote available, at second hand: "Instagram carousels can now be up to 20 slides with 20
  unique captions." Attributed to Engadget via X.

## Claims this source supports

1. Per-slide captioning, if real, changes what an Instagram carousel outline is. It stops
   being one caption plus a set of images and becomes a sequence of copy units, which is
   structurally closer to a LinkedIn document post than it used to be.
2. Carousel slide ceilings are moving. Any hard number the skill writes down about
   Instagram will age.

## What the skill does with this

Treats it as unconfirmed. The format specification guide instructs the model to verify
carousel slide count against the user's own app before building to 20, and to build to 10
when verification is not possible, because 10 renders correctly under both the old and the
new behavior.
