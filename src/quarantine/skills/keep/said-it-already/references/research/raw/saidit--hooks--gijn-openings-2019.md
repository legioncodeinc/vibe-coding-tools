## Extracted content

**Seven opening types.**

| Type | How it works | Example cited |
|---|---|---|
| Start with a person | Introduce a character, then pan out to why they matter | Amelia Gentleman, Guardian: "We know that David Clapson was actively searching for work when he died because..." |
| Start with action | Protagonist doing something specific, establishing setting and momentum at once | "Two or three times a month, Tom Giles says goodbye to his wife..." |
| Start in place | Setting becomes a character | BBC: "Khojabay is a fisherman who lives in a desert" |
| Start with a detail | A striking specific, working as synecdoche | "A tiny pair of shoes, along with nappies for a newborn, sit on shelves..." |
| Start with a question | Reader engaged in solving a mystery | "They Raised $115m for the Fight against ALS. so How Did They Spend It?" |
| Start with a problem | Establish something positive, then disrupt with a concrete fact | ProPublica: "Last year over 1,700 passengers and crew members fell sick from gastrointestinal illnesses like norovirus." |
| Start with revelation | Lead with the finding, inverted pyramid | "Criminals and dishonest debtors are exploiting weaknesses in the bankruptcy system..." |

**Failure mode named.** Overused cliche details, for instance "a child's teddy bear" in
war reporting, which the source notes was satirized in the sitcom Drop the Dead Donkey.

**The trade-off.** "Revelation-based openings guarantee readers receive main points but
risk superficial engagement. Narrative techniques encourage deeper reading but risk
reader abandonment if the payoff delays too long."

**Reader promises.** "Every opening makes implicit promises." Explain why the character
matters, clarify the detail's significance, justify the setting. "Failure to fulfill these
creates frustration."

## Claims this source supports

1. There is a finite, teachable set of opening moves. A hook can be selected
   deliberately per seed type rather than improvised.
2. Concrete specifics beat abstraction in an opening. Every cited example leads with a
   named person, a number, or a physical detail.
3. The opening makes a promise the body must pay off. A hook that oversells the seed is a
   defect, not a growth tactic.
4. Leading with the revelation and leading with the story are both valid and trade off
   against each other. Short-form posts favor revelation, long-form favors narrative.
