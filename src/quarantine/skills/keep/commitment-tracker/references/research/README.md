# Research archive for commitment-tracker

Domain: commitment tracking and follow-through. Swept 2026-08-17 with web search and
direct page fetches.

## How to use this folder

Read `distilled-commitment-tracking.md` first. It is the only file the skill's guides cite
directly, and every claim in it ends in a bracketed pointer to a file in `raw/`. If a
domain claim appears anywhere in this skill without a trail through the distillation to a
raw file, it is a defect.

## Source count

Twelve raw sources. Four academic, two official-docs, three vendor-blog, one practitioner
press, one large-sample vendor research report, one low-trust community blog kept as a
negative finding. The contract minimum is five and the assignment minimum is six.

## Window

Default window was the last six months. Two sources sit outside it and both say so in
their own header: the Gollwitzer and Sheeran meta-analysis (2006, foundational and not
superseded) and the Harvard Business Review follow-up piece (January 2021, retained
because the recent-window search returned only cold-outreach content marketing).
