# ManyChat Community: Clarification about automation and comment reply limits for Instagram

- **Title:** Clarification about automation and comment reply limits for Instagram
- **URL:** https://community.manychat.com/general-q-a-43/clarification-about-automation-and-comment-reply-limits-for-instagram-7813
- **Fetched:** 2026-08-17
- **Source type:** community (ManyChat user forum)

## Source-quality caveat

Community forum, lowest tier of evidence. Archived because the ABSENCE of an official
answer is itself the finding: an operator asking ManyChat support directly for comment
and DM rate limits did not get an official reply in the thread.

## Extracted content

**Stated limits**

No ManyChat staff response appears in the thread. The only answer comes from a community
member posting as AscendDigital:

> "There is no limit so far for comment trigger per hour or per day."

**Community-suggested practices to avoid spam flags**

- "Use only specific keywords to trigger the automations"
- Create "multiple public replies" that are "lengthy and unique"
- Make first DM messages "very clear and specific"
- Use solid buttons rather than quick replies in the initial message
- Duplicate automations are acceptable, but "choose different keywords"

**Escalation status**

The original poster asked for clarification from the support team. No official response
appears in the thread.

## Claims this source supports

1. Operators running these campaigns cannot get a straight answer on rate limits from the
   tool vendor. Planning volume against a published number is not possible.
2. The community's own harm-reduction advice is to vary public reply text so replies do
   not look templated, which is a tacit admission that identical templated replies read as
   spam to the platform.
3. This is a named research gap, not a settled fact. Any volume guidance in this skill is
   directional.
