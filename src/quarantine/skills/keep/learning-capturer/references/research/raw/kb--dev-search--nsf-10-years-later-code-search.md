# 10 Years Later: Revisiting How Developers Search for Code

- **URL:** https://par.nsf.gov/biblio/10618890-years-later-revisiting-how-developers-search-code
- **Fetched:** 2026-08-17
- **Source type:** academic (NSF Public Access Repository, published June 2025)
- **Why archived:** Directly tests whether AI coding assistants displaced search behavior.
  They did not. That matters because a personal knowledge base is a search target, and a
  skill built on the assumption that search is dying would be building for a shrinking
  need.

## Method and scale

- A series of **three surveys**, **1,945 total responses**.
- Usage statistics from **over 100,000 users** of an internal code search tool.
- Follow-up to a 2015 study of **27 Google developers**.
- Published June 2025, comparing against observations from roughly a decade earlier.

## Findings

- Quoted: "Code Search users continue to use the tool frequently and the frequency has not
  changed despite the introduction of AI-enhanced development support."
- Example-seeking persists but "the frequency of example-seeking behavior has decreased."
- Quoted: "More often than before, users access the tool to learn about and explore code."

## Ten-year context stated by the authors

New programming languages, AI code generation tools, better IDE autocomplete, expanded
Q and A forums, and larger repositories all arrived in the interval. Search habits held
steady across all of it.

## What this source does NOT supply

No metrics on query length, session duration, or repeat-search rate in the accessible
content. Do not cite this source for re-finding frequency.
