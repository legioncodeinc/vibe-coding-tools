# Blind Trust in AI: Most Devs Use AI-Generated Code They Don't Understand

- **URL:** https://clutch.co/resources/devs-use-ai-generated-code-they-dont-understand
- **Fetched:** 2026-08-17
- **Source type:** vendor-blog (Clutch, B2B research and reviews firm, reporting its own
  survey)
- **Why archived:** Supplies the number that justifies treating an AI-assisted solve as its
  own entry category. If most developers ship AI code they do not understand, then the
  moment an AI fixes a wall for the user is precisely the moment they will not remember how
  it was fixed, which makes it the highest-value capture in the whole skill.

## Survey details

- Sample: **800 software professionals**
- Fielded: **June 2025**
- Published: **29 January 2026**

## Headline finding

Quoted: "59% of developers say they use AI-generated code they do not fully understand."

## Supporting security data cited in the piece

| Measurement | Value | Corpus |
|---|---|---|
| GitHub Copilot programs containing security flaws | 38.8% | 1,689 programs analyzed |
| Python snippets via Copilot with security flaws | 32.8% | 452 snippets |
| JavaScript snippets via Copilot with security flaws | 24.5% | 452 snippets |

## Stated risks

Poor code quality, security vulnerabilities, compliance exposure, accountability gaps.

## What this source does NOT supply

No verification-rate data, and no documented downstream consequence figures beyond the
security percentages above. The 59% is self-reported.
