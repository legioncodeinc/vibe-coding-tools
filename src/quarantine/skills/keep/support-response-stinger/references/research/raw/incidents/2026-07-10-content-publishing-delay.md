# Content Publishing Delays - Partial Outage

- URL: https://status.gohighlevel.com/incident/950307
- Fetched: 2026-09-04
- Source type: official-status-incident
- Incident observed: 2026-07-10
- Trend window: 2026-06-04 through 2026-09-04 inclusive
- Window role: direct recent incident evidence

## Captured facts

Published changes did not appear immediately because cache refresh was delayed. The provider deployed a fix and reported resolution.

## Safety caveat

Confirm the saved version, published version, live URL, and an incognito result before publishing repeatedly. Repeated publication can create version confusion and does not necessarily clear an upstream cache delay.
