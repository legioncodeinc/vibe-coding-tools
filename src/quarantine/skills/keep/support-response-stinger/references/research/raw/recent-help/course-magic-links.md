# Magic Links In Memberships (Courses)

## Captured facts

A magic link gives one intended customer time-limited password-free authentication and routes that customer to a course, community, or portal destination. It does not grant content permission. Troubleshooting must separately confirm link freshness, recipient identity, enrollment, and access to the intended course or group.

## Safety caveat

Never send one contact's magic link to another person or place it in a shared ticket. If a link expired, generate a new link only for the verified intended contact. Confirm access rights before resending.
