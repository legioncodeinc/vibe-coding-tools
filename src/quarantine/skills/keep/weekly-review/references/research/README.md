## Four things to know before using the distillation

1. **Section 4 dissolves the neutral-versus-motivating question rather than answering it.**
   The axis the evidence supports is task-level versus self-level, not harsh versus kind.
   Do not collapse that into "be neutral".
2. **Section 6 contains a live conflict about how many data points establish a shift**, six
   against eight. The skill takes the conservative reading and says why. Do not smooth it.
3. **Section 11 lists seven numbers that appear in this archive and must never be restated
   as fact.** Check that table before quoting any statistic from these files. The
   setback-versus-progress multiple is the one most likely to be quoted wrongly, because it
   is widely repeated elsewhere and neither archived source quantifies it.
4. **Section 12 lists seven named gaps.** The largest: nothing in this archive tests the
   weekly review itself, tests any solo retrospective format, measures abandonment of
   anything, or studies a machine-generated report about a person's own week. The skill is
   built on transfers and every transfer is labelled.
