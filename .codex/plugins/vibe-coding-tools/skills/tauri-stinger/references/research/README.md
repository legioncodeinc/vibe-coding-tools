# Tauri 2 Domain Research

This folder records stages 2 and 3 of the Queen Bee forge for `tauri-stinger`.

- Research window: 2026-03-03 through 2026-09-03 inclusive
- Retrieval completed: 2026-09-04
- Authority: official Tauri documentation, official `tauri-apps` repositories, package-specific release tags, tagged source manifests, and official repository advisories
- Excluded evidence: community posts, third-party tutorials, search-result summaries without a primary source, and model-memory claims
- Currency rule: every version is a dated observation at the cutoff, not a timeless recommendation
- AI rule: Tauri did not provide a first-party AI reference application in the reviewed sources. AI-specific architectures and examples are derived designs and are labeled as such.

The primary update sweep covers releases and advisories published from 2026-03-03 through 2026-09-03. Mutable official pages for commands, security, persistence, updater setup, testing, signing, and distribution were fetched at the cutoff as supplemental living baseline references. A page footer outside the six-month release window is not treated as evidence of an in-window release. No historical release note or advisory older than the Queen Bee ceiling is used to establish current update behavior.

`raw/` contains one research note per primary source. Every note includes a compact `Captured source material` section with an API, configuration, advisory excerpt, or immutable release identity before its interpretation. `distilled-tauri-2.md` synthesizes the archive, cites every factual claim to a raw note, and names source conflicts instead of hiding them.
