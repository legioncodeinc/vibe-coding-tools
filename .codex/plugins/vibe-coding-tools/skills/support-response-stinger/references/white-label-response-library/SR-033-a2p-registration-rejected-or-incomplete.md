# SR-033: A2P registration is rejected or incomplete

## Use when

Use when an A2P registration is rejected, stalled, or cannot be completed at a specific stage.

## Required evidence

- Registration, brand, campaign, and number identifiers; legal-entity type; use case; current state; exact rejection code; affected field; consent source; and a description of requested documents.

## Customer-facing email

**Subject:** {ticket_id}: Reviewing the A2P registration block

Hi {customer_first_name},

I understand that your A2P registration was rejected or cannot move forward. We first need to identify whether the block is at the brand, campaign, vetting, use-case, or number-linkage stage so we address only the displayed requirement.

Please send the registration, brand, campaign, and number identifiers, legal-entity type, use case, current state, exact rejection code, affected field if shown, and consent source. Describe the documents requested, but do not email unredacted identity documents. If formal documents are required, wait for an approved secure upload method from {agency}.

I will review the displayed requirement and route unexplained rejection codes, regional eligibility, or legal and consent questions to our compliance specialist. We cannot promise approval, suggest a bypass, or confirm eligibility before that review.

{agent_name}
{agency} Support

## Agent notes

Evidence class `F2`. Remediation class `R1`. Classify the exact registration stage before advising. Compliance review is required for regional eligibility, legal interpretation, consent interpretation, and unexplained codes. Never request unredacted identity files by email.
