# ICP-relevancy scoring rubric template

Bridges the build plan's universal zero-to-six scale (`plan/website-auditor-build-plan.md`
section 4.1) to this Stinger's specific `[subjective]` ICP-relevancy
checkpoint. Copy this rubric into the run's working notes (or reference it
directly) before scoring section 2 of
`references/templates/content-semantics-report-template.md`, so every
page's 1-6 score is applied against the same stated criteria rather than
an ad hoc per-page judgment.

**Grounding note:** no source in this Stinger's research archive defines an
ICP-relevancy scoring methodology (`references/research/distilled-content-
semantics.md` section 8 names this explicitly as a gap; the closest
material, "non-commodity content," is Google's own term for Google's own
systems, not a general ICP-relevancy framework). The rubric below is this
Stinger's own construction, built to apply `icp-positioning-stinger`'s
already-grounded taxonomy (firmographic/technographic/behavioral
attributes, the macro/micro conversion-action split, the three-stage
awareness/consideration/decision funnel) to a single page's copy, rather
than inventing new ICP vocabulary. Cross-link that Stinger's output; do not
re-derive its taxonomy here.

| Score | Grade | Definition for this checkpoint |
|---|---|---|
| 0 | N/A | Page type is not one a content-relevancy judgment applies to (e.g. a legal/utility page with no persuasive or informational purpose toward any ICP segment). Excluded from scoring. |
| 1 | F | Page content is actively off-ICP: targets or reads as written for an anti-ICP segment `02-positioning/` names, or contains no discernible connection to the site's stated niche at all. |
| 2 | D | Page is generically relevant to the industry but not to the specific ICP; could equally serve a segment `02-positioning/` explicitly excludes. |
| 3 | C | Page serves the broad ICP but not any specific funnel stage or conversion action; reads as written for "anyone interested," not for the ICP's actual buying-stage signals. |
| 4 | B minus | Page maps to a specific ICP attribute or funnel stage (awareness/consideration/decision, per `icp-positioning-stinger`'s three-stage model) but the copy does not clearly signal that mapping to the reader. |
| 5 | B | Page maps clearly to a specific ICP attribute and funnel stage, with copy that speaks to that segment's actual concerns. |
| 6 | A | Page maps clearly to a specific ICP attribute and funnel stage, speaks directly to that segment, AND clears the non-commodity bar (offers distinct value beyond restating widely available information, per Google's stated content-quality bar). [raw/www-semrush-com-blog-google-publishes-generative-ai-search-guide.md] |

Every score still needs its evidence pointer and one-line justification,
per conduct rule 2. State which specific `02-positioning/` attribute or
funnel stage the page maps to (or fails to map to) by name in the
justification; "seems relevant" is not a justification.
