# Identify shared boundaries before PRD authoring

1. Read the feature brief, existing PRD indexes and sub-PRDs, existing `CTR-*` records, applicable ADRs, and source schemas or interfaces. Record the provider or producer and every known consumer. A contract is worth extracting when at least two independently owned work streams rely on the same observable behavior. [../references/research/raw/pact-contract-testing.md](../references/research/raw/pact-contract-testing.md)
2. Use `templates/boundary-inventory.md` to list each shared boundary as one row: ID or proposed name, provider, consumers, source, unknowns, affected PRDs, and whether the unknown blocks parallel PRD completion. Include HTTP operations, events, shared models, permission decisions, state transitions, and external service handoffs when they are shared. Use the protocol references to avoid omitting required surface details. [../references/research/raw/openapi-specification.md](../references/research/raw/openapi-specification.md) [../references/research/raw/asyncapi-specification.md](../references/research/raw/asyncapi-specification.md) [../references/research/raw/json-schema-specification.md](../references/research/raw/json-schema-specification.md)
3. Reuse an accepted `CTR` record if it covers the exact boundary and revision. If a governing ADR or schema contradicts it, flag the contradiction and stop the affected work until the owner resolves it. Do not silently choose one source.
4. Mark each boundary `accepted`, `draft`, or `missing`. Send the `draft` and `missing` rows to the contract-writing Drone before Library assigns parallel PRD authors. Independent sections may be drafted while a shared normative decision remains open, but an affected PRD cannot be finalized.
5. Report a concrete readiness result: `ready for parallel PRD completion` only when every shared boundary has an accepted revision with named owners and no open normative decision. Otherwise report the exact blocked PRDs and the smallest decision needed to free them. Mixed-version behavior is part of the boundary, since producers and consumers can deploy separately. [../references/research/raw/protobuf-best-practices.md](../references/research/raw/protobuf-best-practices.md)

This inventory is a Wasp Nest coordination method, not a claim that any cited specification requires pre-PRD contract records. [../references/research/distilled-contract-writing.md](../references/research/distilled-contract-writing.md)
