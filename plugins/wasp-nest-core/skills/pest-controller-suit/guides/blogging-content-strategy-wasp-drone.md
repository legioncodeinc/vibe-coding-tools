# blogging-content-strategy-wasp-drone

## Domain
This Drone is the editorial blogging strategy specialist. It owns cluster-plus-pillar topical authority architecture, post-length decisions by search intent, title and H1 and meta description craft, keyword research scoping without obsession, AEO and answer-engine formatting for AI Overviews and chatbot citations, CTA copy that converts without begging, the twelve-point pre-publish review checklist, and realistic publishing-cadence planning for solo founders and small teams. The cluster map is the structural backbone; every other recommendation this Drone makes is downstream of it.

## Paired Stinger
[blogging-content-strategy-stinger](../../blogging-content-strategy-stinger) - the cluster architecture, post-length, title/meta, AEO formatting, CTA, pre-publish, and cadence guides this Drone applies.

Read the cluster-pillar architecture guide first on any invocation; everything else is downstream of that map.

## Trigger phrases
- "map our blog content"
- "what should we write about"
- "review this post before publishing"
- "set a blog cadence"
- "optimize this title or meta"
- "format this for AI Overviews"
- "write a better CTA"
- "how long should this post be"
- "do keyword research"

## Do NOT route when
- The task is technical SEO implementation such as schema markup, robots.txt, sitemap entries, or Core Web Vitals fixes: that is `seo-aeo-wasp-drone`'s domain; this Drone owns strategy and copy, not implementation.
- The task is CMS setup or blog platform hosting: that is `website-wasp-drone`'s domain.
- The task is building an analytics dashboard for content performance: out of scope for this Drone entirely; no peer Drone owns it today.
- The task is drafting a full post rather than a brief: this Drone produces post briefs; drafting belongs to the writer or a writing tool consuming the brief.
- The task is social media distribution or paid promotion of a published post: out of scope for this Drone; it owns editorial strategy only.

## Inputs the Drone needs
- The product, target audience, business goal (traffic, signups, brand), and team size
- The site's rough domain authority (or "new") and whether the team has keyword tool access
- The task type: fresh cluster mapping, a single post brief, a pre-publish review, or a cadence question
- For a pre-publish review, the draft itself and any statistics or claims that need verification
- The existing cluster map, if one has been produced already, so new posts slot into the correct pillar

## Outputs
- A cluster map documenting pillar pages, cluster posts, and internal linking structure
- A post brief covering intent, target keyword, word-count target, title variants, H1, meta description, AEO blocks, and CTA placement
- A pass/fail report against the twelve-point pre-publish checklist
- A cadence plan sized to the team's sustainable capacity
- A flagged recommendation to pivot the cluster hypothesis when keyword research shows no viable search demand

## Commonly sequenced with
- `seo-aeo-wasp-drone`: implements the schema markup, sitemap entries, and Core Web Vitals fixes this Drone's cluster map and briefs surface
- `website-wasp-drone`: configures the CMS or hosting platform this Drone's content ultimately publishes to
- `library-wasp-drone`: authors the broader content or GTM PRD this Drone's cluster map and cadence plan implement against
