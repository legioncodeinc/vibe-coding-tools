# Browser automation reference

| Evidence | Minimum record |
|---|---|
| Test result | Tool version, browser channel, target URL, test revision, exit status |
| Failure | Screenshot or trace, console and network context with secrets redacted |
| CI | Browser installation step, cache policy, artifact retention, retry policy |
| External effect | Explicit authorization and a unique test fixture or idempotency guard |

Source basis: [distilled-browser-automation.md](research/distilled-browser-automation.md).
