# Reference: Branded PDF Report Outline

The page sequence used in the field-tested reference build. Adapt to what was actually requested; a report the user did not ask to be this long should not be padded to match this outline.

## 1. Cover
Dark or brand-primary background (or light, if that is the brand's convention). Full logo lockup, a short tag/eyebrow (e.g. the brand's own tagline), report title (2 lines max), one-sentence subtitle stating what the report covers, and 3-5 headline stats along the bottom (companies reviewed, categories, gap count, battlecard count). Prepared-date line.

## 2. Executive Summary
4 stat tiles (computed numbers, each with a one-line label explaining what it means, not just a bare number). One short framing paragraph. Two columns: "Close first" (top gaps/risks, bulleted, action-oriented) and "Protect and lead with" (genuine differentiators, bulleted).

## 3. Market Pattern Analysis
The insight page. 2-4 named sections, each a claim as its heading followed by prose (not bullets) stating a computed statistic and its implication. 1-2 single-hue charts (see Guide 04 on the categorical-palette trap) backing the closest-category statistics. A "smaller signals worth tracking" closing section for secondary trends.

## 4. Competitor Breakdown (one page per category, or as many pages as needed)
A table per category: Company, Starting Price, Identification/Notes, How It Compares. Sort largest category by whatever makes sense (alphabetical is safe); keep a category to one page if the row count allows, splitting to a continuation page (clearly labeled "continued") if not, per the overflow guard in Guide 04.

## 5. Sales Battlecards
One card per closest competitor (5-6 total), 2-3 per page. Each card: name, target profile, italicized one-line pitch in quotes, two-column "where they win / where the subject wins," and a talk-track block. Left border accent in the category's brand color.

## 6. Feature Roadmap
Legend row (Gap/Partial/Have dot colors). One row-card per feature: name, Status and Priority chips top-right, "seen in" line, one-sentence rationale. Group by priority or leave in table order; either is acceptable, group by priority if the list exceeds ~12 items.

## Footer (every interior page)
Small brand mark (correctly recolored, see Guide 04 Defect 1) plus an eyebrow label naming the page's section, the subject's name bottom-left, report title and date bottom-right.
