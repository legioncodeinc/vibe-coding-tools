# Contracts

One CTR records one shared, observable boundary. The contract-writing Drone drafts the terms and records the user's acceptance of the exact revision. The Library Drone links accepted revisions from each affected PRD under `## Contract dependencies` and maintains those links as PRD folders move.

Use `CTR-<###>-<slug>.md` with the next unused number. Do not treat Draft text as an accepted agreement. Legal agreements do not belong here.
