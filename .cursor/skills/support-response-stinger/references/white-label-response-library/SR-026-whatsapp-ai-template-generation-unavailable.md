# SR-026: WhatsApp AI template generation is unavailable

## Use when

Use when AI-assisted generation of a WhatsApp template is unavailable while existing templates may still be intact.

## Required evidence

- Workspace, attempted template, timestamp and timezone, exact generator behavior, existing approval state, and whether manual template creation is available.

## Customer-facing email

**Subject:** {ticket_id}: Checking unavailable WhatsApp template generation

Hi {customer_first_name},

I understand that AI-assisted WhatsApp template generation is unavailable. The first priority is to preserve any existing approved content and determine whether the problem is limited to generation.

Please send the workspace, attempted template name, time of the latest attempt with timezone, and a redacted description or screenshot of the generator behavior. Include the current approval state of existing templates and tell me whether manual template creation remains available.

Please do not delete templates, reconnect WhatsApp, or resubmit approved content solely because generation fails. I will isolate the affected function and send the evidence to our technical team if it remains unavailable. We have not confirmed a current service-wide issue or a cause.

{agent_name}
{agency} Support

## Agent notes

Evidence class `F1`. Remediation class `UNRESOLVED`. Apply `HR-13`. Preserve existing approved templates. Stop after confirming generation-only scope and escalate without reconnecting or resubmitting content.
