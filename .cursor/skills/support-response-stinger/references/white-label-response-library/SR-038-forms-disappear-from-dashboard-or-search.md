# SR-038: Forms disappear from the dashboard or search

## Use when

Use when existing forms are missing from the expected dashboard view or search results.

## Required evidence

- Workspace, form identifier and name, dashboard view or search term, live and share page addresses, browser, timestamp and timezone, screenshot, recent-view result, existing submissions, and page or embed assignment.

## Customer-facing email

**Subject:** {ticket_id}: Locating forms missing from the dashboard

Hi {customer_first_name},

I understand that forms have disappeared from the dashboard or search. Before anything is recreated, we need to verify the active workspace and determine whether the existing forms still appear in Recent, at their current live page, or in their existing embed.

Please send the workspace, form name and identifier, dashboard view or search term, live and share page addresses, browser, and time with timezone. Include a screenshot, the Recent-view result, whether existing submissions remain visible, and the current page or embed assignment.

Please do not replace, recreate, republish, or delete the forms. I will preserve the asset inventory and compare the dashboard, Recent, live, and embed states. If the forms remain missing, I will send the evidence and dependency list to our technical team.

{agent_name}
{agency} Support

## Agent notes

Evidence class `F2`. Remediation class `R2`. Apply `HR-13`. Protect form submissions and dependencies before action. Escalate a preserved inventory if the object remains missing across the relevant views.
